# Gentle

![Gentle app banner](./gentle-banner.svg)

## Description

Gentle is a calm, distraction-light writing app for creating and editing documents. It brings a focused rich-text editor, a choice of color themes, and OpenDocument Text (`.odt`) support together in one desktop app.

## Features

- Eight themes: Rosewater, Lavender, Sky, Sage, Berry Dusk, Amethyst, Midnight, and Evergreen.
- Rich-text formatting with bold, underline, strikethrough, headings, lists, quotes, alignment, links, and adjustable line spacing.
- Create documents, change their names, open `.odt` files, and save documents as `.odt`.
- Insert images from a file, paste them from the clipboard, or drag and drop them into the editor.
- Undo and redo, plus keyboard shortcuts for common actions.
- Desktop app for Windows, with document files saved locally.

## Known Bugs

- Italic formatting is currently not working reliably.
